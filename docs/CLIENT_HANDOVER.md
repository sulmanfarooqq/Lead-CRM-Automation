# Client handover checklist

- [ ] Confirm lead sources and form fields.
- [ ] Confirm priority thresholds and follow-up service levels.
- [ ] Confirm active sales representatives and routing rules.
- [ ] Confirm Monday.com board, group and exact column IDs.
- [ ] Configure secrets in hosting environment variables, never in Git.
- [ ] Configure SMTP and/or Slack destinations with client approval.
- [ ] Test new lead, repeat lead, invalid contact and invalid secret.
- [ ] Test CRM and notification outages.
- [ ] Confirm persistent storage and database backup.
- [ ] Deliver webhook URL, API docs, walkthrough video and support details.
- [ ] Obtain explicit approval before enabling buyer-facing email or SMS.
